# 🌦️ SIH26074 - Panchayat Weather AI

## 📌 Project Overview

Panchayat Weather AI is a smart weather and agriculture
support platform designed for rural communities.

The system provides:

- Weather information
- Weather alerts
- Forecast information
- Farmer recommendations
- AI-based rainfall prediction
- Location-based weather monitoring
